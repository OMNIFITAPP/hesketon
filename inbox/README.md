# 📥 inbox — איך יוצרים פוסט (שלב ידני)

כל קובץ `.md` כאן הוא "brief" — פרק אחד שרוצים להפוך לפוסט.

## הזרימה

1. **העתיקו** את `_example-episode.md` לקובץ חדש בשם משלכם, למשל `huberman-sleep.md`
   (אל תתחילו את השם ב־`_` — קבצים כאלה נחשבים תבניות ומדולגים).
2. **מלאו** את הפרטים בראש הקובץ (פודקאסט, פרק, אורח, קישור יוטיוב).
3. **הדביקו** את התמלול המלא של הפרק בגוף הקובץ (אפשר באנגלית).
   - איך משיגים תמלול ידנית: ביוטיוב → תחת הסרטון `...` → **Show transcript** → להעתיק הכול.
4. הריצו:
   ```bash
   npm run new-post
   ```
5. נוצרת **טיוטה** ב־`src/content/posts/` עם `draft: true`, וה־brief עובר ל־`inbox/_processed/`.
6. הריצו `npm run dev`, עברו על הטיוטה, ערכו אם צריך, ואז שנו `draft: false` ושמרו.
7. עשו commit ו־push — והאתר יתעדכן לבד.

## טיפים

- אין צורך לנקות את התמלול — Claude מתמודד עם חזרות וה"אֶה" של הדיבור.
- בלי מפתח API? הריצו `npm run new-post:dry` כדי לוודא שהצינור עובד (בלי לכתוב תוכן אמיתי).
- התמלולים האלה **לא נשמרים ב־git** (ראו `.gitignore`) — הם נשארים אצלכם בלבד.

## שלב 2 (אוטומטי)

כשתעברו ל־Apify, לא תצטרכו להדביק תמלולים: פשוט תוסיפו קישור יוטיוב ל־`content-queue.yml`,
וה־GitHub Action ימשוך את התמלול, יכתוב טיוטה ויפתח לכם Pull Request לאישור מהטלפון.
